[h1]As Above, So Below 简体中文汉化补丁[/h1]

将 [b]As Above, So Below[/b] 模组的全部界面文本、设置选项和物品描述完整翻译为简体中文。

[hr][/hr]

[h2]翻译内容[/h2]
[list]
[*]模组设置界面 — 所有选项标签、工具提示、按钮文字
[*]建筑物（楼梯、电梯、管道等）名称和描述
[*]生物群系描述
[*]工作类型和按键绑定
[*]地形名称和描述
[*]共计 270+ 条文本
[/list]

[hr][/hr]

[h2]说明[/h2]
本模组使用 RimWorld 内置的本地化系统，[b]不修改[/b]原模组的任何文件，可与原模组一起正常更新。

[h2]依赖[/h2]
[list]
[*][b]As Above, So Below[/b] (astryl.AsAboveSoBelow)
[/list]

[h2]安装[/h2]
[olist]
[*]确保已安装 As Above, So Below 原模组
[*]将本模组放入 RimWorld/Mods/ 目录
[*]在游戏 Mod 列表中启用（置于原模组之后加载）
[/olist]
