# As Above, So Below II 简体中文汉化

[![Steam 工坊](https://img.shields.io/badge/Steam-%E5%B7%A5%E5%9D%8A-blue?style=flat&logo=steam)](https://steamcommunity.com/sharedfiles/filedetails/?id=3769988812)

## 简介

将 [**As Above, So Below II**](https://steamcommunity.com/sharedfiles/filedetails/?id=3776015553) 模组的全部界面文本、设置选项和物品描述翻译为简体中文。

**源模组作者：** astryl

## 翻译内容

- 模组设置界面 — 所有选项标签、工具提示、按钮文字
- 建筑物（楼梯、电梯、梯子、电力立管等）名称和描述
- 生物群系描述
- 按键绑定
- 地形名称和描述
- 兼容模组立管（Dubs Bad Hygiene、Rimefeller、Rimatomics、Vanilla Chemfuel Expanded、Vanilla Temperature Expanded、Luciferium Expanded）
- 共计 130+ 条文本

## 依赖

- [**As Above, So Below II**](https://steamcommunity.com/sharedfiles/filedetails/?id=3776015553)（astryl.AsAboveSoBelow2）

## 安装

1. 确保已安装 As Above, So Below II 原模组
2. 将本模组放入 `RimWorld/Mods/` 目录
3. 在游戏中启用（置于原模组之后加载）

## 说明

本模组使用 RimWorld 内置的本地化系统，**不修改**原模组的任何文件，可与原模组一起正常更新。
