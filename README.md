# RimWorld Mods

RimWorld 模组项目合集，包含多款模组的简体中文汉化、Bug 修复补丁以及功能模组。

## 项目列表

### 🌐 汉化模组

| 项目 | 说明 | 源模组 |
|------|------|--------|
| [AsAboveSoBelow-ZhCN](./AsAboveSoBelow-ZhCN/) | As Above, So Below 简体中文汉化 | [Steam 工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3767572810) |
| [TailorMade-ZhCN](./TailorMade-ZhCN/) | TailorMade 简体中文汉化 | [Steam 工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3014568497) |
| [asrtylsUIMod-ZhCN](./asrtylsUIMod-ZhCN/) | astryl UI 模组合集简体中文汉化（聚合 18 个 UI/工具模组，含 Modern 系列、True RPG 系列等） | [Steam 工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=2957620250) |
| [NiceResearchTab-ZhCN](./NiceResearchTab-ZhCN/) | Nice Research Tab 简体中文汉化 | [Steam 工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3773496046) |

### 🔧 修复模组

| 项目 | 说明 |
|------|------|
| [TailorMadeUnlockFix](./TailorMade-ZhCN/TailorMadeUnlockFix/) | 修复 TailorMade 的跨种族服装限制开关无效 |

### 🔌 功能模组

| 项目 | 说明 |
|------|------|
| [ModernExpandMenu](./ModernExpandMenu/) | MD3（Material Design 3）风格分组右键菜单，替代原版扁平菜单 |
| [NotificationsONWindowsNOW](./NotificationsONWindowsNOW/) | 游戏内通知实时推送到 Windows 通知中心 |
