# 【模组名】简体中文汉化

将 [**【模组名】**](https://steamcommunity.com/sharedfiles/filedetails/?id=【steamID】) 模组的全部界面文本、设置选项和物品描述翻译为简体中文。

**源模组作者：** 【原模组作者】

## 翻译内容

- 模组设置界面 — 所有选项标签、工具提示、按钮文字
- 物品 / 建筑 / 生物的名称和描述
- 共计 【条数】+ 条文本

## 依赖

- [**【模组名】**](https://steamcommunity.com/sharedfiles/filedetails/?id=【steamID】)（【原packageId】）

## 安装

1. 确保已安装【模组名】原模组
2. 将本模组放入 `RimWorld/Mods/` 目录
3. 在游戏中启用（置于原模组之后加载）

## 说明

本模组使用 RimWorld 内置的本地化系统，**不修改**原模组的任何文件，可与原模组一起正常更新。

## 构建与部署

运行 `build.bat` 自动部署到游戏 `Mods` 目录。
