# 模组更新日志格式规范

统一各模组发布到 Steam 创意工坊时的「更新说明（Change Notes）」格式，保证玩家看到的更新日志清晰、一致、重点突出。

## 语言

- 默认**简体中文**
- 若模组界面含英文（如 NotificationsONWindowsNOW），可附英文版，**中文在前、英文在后**

## 结构

```
<模组名> <版本号（可选）> 更新说明

**新增**
- <新功能 / 新设置项>

**改进**
- <现有功能优化 / 体验提升>

**修复**
- <Bug 修复，写明具体问题>

**其他**
- <兼容性 / 安全说明 / 文档变更>
```

## 条目规则

| 项 | 规则 |
|----|------|
| 标题 | `模组名 更新说明`，或带版本号 `模组名 v1.1.0 更新说明` |
| 分类 | 按「新增 / 改进 / 修复 / 其他」分组，**无改动则省略该组** |
| 条目 | 每条一行，`- ` 开头；「动词 + 对象 + 结果」，一条讲一件事 |
| 面向用户 | 只写**玩家能感知**的改动，不写内部实现（Harmony 补丁、命名管道、代码重构等一律不写） |
| 具体化 | 涉及数值/选项时给出具体值（如「合并窗口 0~10 秒可调」「200 毫秒内相同内容合并」） |
| 排序 | 重要功能排前，修复按影响程度排序 |

## 编写流程

1. **对比上一发布版本**：用 `git log` 查看该模组相关提交，或读 `_AIcoding/_notes.md` 的待办/记录
2. **提取用户可见改动**：过滤掉内部细节，只留玩家能感知的功能、修复、体验变化
3. **按分类整理**：重要新增排最前，修复写明问题现象
4. **中文撰写**；需要英文时逐条翻译（术语与工坊界面一致）

## 示例（NotificationsONWindowsNOW）

**Notifications ON Windows NOW 更新说明**

**新增**
- 模组设置页（游戏内「选项 → Mod 设置」）：通知合并窗口调节（0~10 秒）、短时间消息去重开关
- 中英双语界面，随游戏语言自动切换

**改进**
- 通知合并：同一事件（如袭击）的信件及伴随消息自动合并为一条；独立系统消息（如存档提示）单独推送
- 防刷屏：同一时刻（200 毫秒内）的相同内容自动合并为一条

**修复**
- 修复通知内容中 `<color>` 等标签原样显示的问题，现在为干净纯文本
- 修复 Windows 10 下通知被系统静默丢弃的问题（自动注册 AUMID）

**其他**
- About 页面注明模组包含的额外可执行程序

## 维护

- 当前版本更新日志草稿：写入各模组 `_AIcoding/_notes.md` 的「更新日志草稿」小节，发布后归档
- 历史存档：如需长期保存，在模组目录放 `CHANGELOG.md`，按版本倒序追加
