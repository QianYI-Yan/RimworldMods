# Nice Research Tab 简体中文汉化

将 [**Nice Research Tab**](https://steamcommunity.com/sharedfiles/filedetails/?id=3773496046) 模组的全部界面文本、设置选项和标签页元素翻译为简体中文。

**源模组作者：** Andromeda

## 翻译内容

- 模组设置界面 — 通用 / 打包器 / 性能三个标签页的全部选项与提示
- 研究标签页 UI — 研究、停止研究、加入队列、研究队列、筛选提示等
- 研究分类 — 护甲、电力、炮塔、武器
- 硬编码字符串 — 性能预设（高/中/低/自定义）、当前研究剩余时间等，通过 Harmony 运行时翻译
- 共计 40+ 条文本

## 依赖

- [**Nice Research Tab**](https://steamcommunity.com/sharedfiles/filedetails/?id=3773496046)（Andromeda.NiceResearchTab）
- [**Harmony**](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077)（brrainz.harmony）

## 安装

1. 确保已安装 Nice Research Tab 原模组
2. 将本模组放入 `RimWorld/Mods/` 目录
3. 在游戏中启用（置于原模组之后加载）

## 说明

本模组使用 RimWorld 内置的本地化系统 + Harmony 运行时翻译，**不修改**原模组的任何文件，可与原模组一起正常更新。

## 构建与部署

运行 `build.bat` 自动编译补丁并部署到游戏 `Mods` 目录。
