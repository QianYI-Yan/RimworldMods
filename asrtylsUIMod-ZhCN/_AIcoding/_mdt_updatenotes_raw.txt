Welcome to Modern Dev Tools, a modern overhaul of RimWorld's developer tools.\n\nNew in 1.3 - playing well with others\n- Other log mods keep working: HugsLib and Archotech Logs add their own buttons to RimWorld's original debug log. Because this mod replaces that window, those buttons used to disappear silently. They now appear in an add-on tray along the bottom of the modern log - including HugsLib's Share logs, Files and Copy - restyled to match the rest of the window.\n- Archotech Logs integration: its Diagnostics and Export windows open straight from the tray, and they follow whichever message you select.\n- A Vanilla log button opens RimWorld's original window any time, and a new Log window setting hands the log back to vanilla completely if you would rather another mod own it.\n\nLog spam throttle (optional, off by default)\n- When the same error repeats endlessly, RimWorld still builds a full stack trace and writes to the log file for every single repeat. Worse, it only collapses repeats that arrive back to back, so two errors alternating are never collapsed at all.\n- Turn this on to stop writing a line after the first few. The first few always come through, the number held back is shown next to the message, and it is counted toward the error's severity - so nothing is hidden from you.\n- This hides symptoms, not causes. Fix the underlying error.\n\nFaster panels\n- Text measurement, error analysis and mod ranking are now cached instead of being recomputed several times per frame.\n- The knowledge base only draws the rows you can actually see, so long lists no longer cost anything off screen.\n- The two experimental hardening features and the spam throttle only install their patches while switched on, instead of always running.\n\nFor mod authors\n- Public API v2: add your own knowledge sources, add a button to the log window, or listen for completed analyses. The button signature matches HugsLib's, so one method works with both.\n- New: bridge another mod's diagnostics into the log entirely from XML, with no code and no hard dependency.\n- See Documentation/RootCauseAnalysis.md.
