# ModernExpandMenu 动画需求规格（给 Gemini 做 demo 用）

> 目标：RimWorld 模组的右键分组菜单（MD3 风格悬浮窗），动画整体追求 **Material Design 3 / 安卓 Material Motion** 的丝滑质感：柔和、有物理感、快速起步指数减速到位（ease-out）。所有时长/速度均可调。

---

## 一、总体风格

- **MD3 Motion**：动画快而柔和，主缓动为「快速起步、指数减速到位」（安卓 ease-out 曲线：`animated += (target - animated) * k`）。
- 同一时刻只允许相关的元素运动，避免整屏乱动；元素逐个、有序地出现（串行），像终端控制台逐行输出。
- 所有动画时长/速度/间隔都做成**可调参数**，实时预览。

---

## 二、动画场景

### 1. 窗口弹出（右键出现时）
- 从 `0.85~0.9` 倍缩放放大到 `1.0`，叠加轻微淡入。
- 时长约 `0.18s`，ease-out。
- 窗口定位在鼠标附近，跟随鼠标弹出。

### 2. 组标题出现（首次加载 / 滚动进入可视区）
- 每个分组标题**逐条出现**（一条就位后才出现下一条）。
- 动画：**水平从左向右滑入**（`-20px → 0`）+ **淡入**（alpha `0 → 1`）。
- 组与组之间**并行**（各自独立推进），组内串行。

### 3. 子项目出现（展开分组 / 滚动进入可视区）
- 组展开后，子项目**逐条串行**出现。
- 每项：水平滑入 + 淡入（同组标题）。
- **严格串行**：上一条的动画完整播放结束 + 间隔后，下一条才开始。
- 子项目在「进入视口过半」时播放出现，滚出视口过半时播放消失（淡出 + 下滑）。

### 4. 分组展开 / 折叠
- 点击组标题：子项目区域**平滑展开/收起**（高度动画），窗口高度随之平滑增长/收缩。
- 展开过程中子项目逐条出现；收起过程中按进度平滑缩回（下一组平滑上移，不闪跳）。
- 展开速度可调。

### 5. 加载动画（右键大量物品、分帧处理时）
- **顶部缓冲加载条**（脉冲呼吸 + 前端光标亮点）。
- **中央环形进度**（平滑圆环，非离散点）+ 百分比 + 半透明覆盖层。
- 子项目**逐条从底端插入**（类控制台输出），加载时滚动**自动跟随底部**（新条目在底部出现并跟随可见）。
- 加载完成后：平滑滚动回顶（见第 6 点）。
- 加载条在加载完成后常驻显示（满条），悬停显示统计 tooltip。

### 6. 回顶动画（加载完成后）
- 从底部平滑滚回顶部。
- 用户手绘曲线：**逐渐加速 → 中段最高速猛冲 → 再逐级减速到顶端**（不是简单的 ease-out）。
- 固定时长（默认 `0.6s`），ease-out-cubic 风格。

### 7. 窗口高度动态
- 加载插入 / 分组展开折叠时，窗口高度**平滑过渡**（不跳变）。
- 达到最大高度后改为内容滚动。

### 8. 滚动进出动画
- 内容滚动时：
  - 进入可视区的项 → 播放出现动画（滑入 + 淡入）。
  - 滚出可视区的项 → 播放消失动画（淡出 + 下滑）。
- 已展开的组滚出视口**不收起**（保留展开状态），滚回时直接显示。

### 9. 滑动开关（安卓开关）
- 圆点滑动动画用安卓 ease-out 曲线（快速起步、指数减速到位），非匀速。

---

## 三、关键可调参数（设置界面滑块）

| 参数 | 说明 | 默认 |
|---|---|---|
| 单条滑入时长 | 每条子项目/组标题滑入动画时长 | 0.25s |
| 相邻项间隔 | 上一条就位后到下一条开始的间隔 | 0.03s |
| 窗口弹出时长 | 右键弹出缩放动画时长 | 0.18s |
| 分组展开/收起速度 | 越高越快 | 10 |
| 滚动跟随速度 | 加载时滚动跟随底部的速度 | 80 |
| 回顶时长 | 加载结束平滑回顶固定时长 | 0.6s |
| 窗口高度动画速度 | 窗口高度过渡速度 | 200 |
| 加载条额外显示秒数 | 加载完成后进度条额外停留 | 0.5s |
| 动画总开关 | 关闭后停用所有动画 | 开 |

## 四、demo 期望（给 Gemini 的具体要求）

请用 **Unity IMGUI / 简单矩形 + 文本** 做一份可交互 demo，模拟这个右键分组菜单的动画，重点是：
1. 窗口弹出缩放（0.85→1.0 + 淡入）。
2. 组标题逐条出现（左滑入 + 淡入）。
3. 点组标题展开：子项目逐条串行左滑入，组高度与窗口高度平滑增长。
4. 子项目滚出视口淡出下滑、滚回视口重新滑入。
5. 底部加载条 + 中央环形进度 + 逐条底端插入 + 滚动跟随底部 + 回顶曲线。
6. 全部用 ease-out（快速起步、指数减速）缓动；参数可拖。
