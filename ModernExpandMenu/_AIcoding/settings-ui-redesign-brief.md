# ModernExpandMenu 设置界面重构说明书（供 Gemini UI 重写）

> 本文档完整描述「模组设置界面」的现状与重构目标，供你（Gemini）产出 UI 方案 / HTML 原型。
> 语言：中文。产出请同时给「HTML 交互原型」+「可移植到 RimWorld 的布局/组件规范」。

---

## 一、项目背景

- **游戏**：RimWorld 1.6（即时模式 GUI，每帧全量重绘，无 DOM / CSS / 自动布局引擎）
- **模组**：ModernExpandMenu（简称 MEM，mod ID `yintx.deepseek.modernexpandmenu`）
- **功能**：① 储物容器右键 → MD3 风格分组悬浮菜单；② 大量原版 UI 可选 MD3 化（窗口/按钮/复选框/菜单区块/管制栏/信息卡/统计/文化）；③ 强大的设置界面
- **技术栈**：.NET Framework 4.7.2、Harmony 补丁、Unity GUI 手绘（`GUI.DrawTexture` / `Widgets.Label` / 自绘圆角纹理等），全部控件为自绘 MD3 风格
- **视觉风格**：Material Design 3（MD3）深色主题，色板 Token 化、两套独立配色（扩展菜单配色 + 杂项配色）

---

## 二、重构目标（核心需求）

把现在的设置界面从「**两大类 tab + 子 tab + 左预览区**」布局，重构为：

> **一个"模组设置聚合大页面"：左侧列表列出所有已安装且有设置界面的模组，点击列表项后，右侧面板显示该模组的设置内容。**

具体要求：
1. **左侧**：纵向列表，列出所有已安装、有设置界面的模组（含本模组 MEM 自己）。
2. **右侧**：选中模组的设置面板（内容区域，支持滚动）。
3. 列表项选中态高亮；切换模组时右侧面板平滑过渡（可选动画）。
4. 视觉上必须保持 **MD3 深色风格**（本模组的视觉招牌），不得退化为原版灰色控件。
5. 本模组 MEM 自己的设置内容 = 下文「现状」中描述的全部内容，全部迁移进右侧面板。

### 3.4 配色体系（Token 化）

两套独立配色，各 13 个 Token，全部可自定义（hex）：
- **扩展菜单配色**（`MD3Theme`）：右键菜单、设置界面本身用

Token：`Primary / OnPrimary / Surface / SurfaceContainer / SurfaceContainerHigh / OnSurface / OnSurfaceVariant / Outline / DisabledText / Shadow / ScrollbarTrack / ScrollbarThumb / ScrollbarThumbDragging`

## 四、技术约束（RimWorld 环境硬限制）

1. **即时模式 GUI**：每帧全量重绘，无事件回调、无 DOM；所有状态需自存（静态字典）。
2. **无布局引擎**：所有控件位置手动 `Rect` 计算，需提供明确的尺寸/间距常量。
3. **无 CSS / 动画库**：动画用 `Time.realtimeSinceStartup` + 缓动函数逐帧插值；无圆角滤镜，圆角用预生成纹理 9-slice。
4. **字体**：游戏字体（中文/英文/繁体），`Text.Font/Anchor` 每帧需复位。
5. **窗口**：`Window.DoWindowContents(Rect)` 绘制；支持滚动视口（自绘 MD3 滚动条）。
6. **多语言**：所有文案走 Keyed 翻译键（中文简体/中文繁体/English）。
7. **聚合技术方案（供参考）**：左侧列表 = 遍历所有已加载模组的 `Mod`，取有设置界面的（`SettingsCategory()` 非空 / `GetSettings<ModSettings>()` 有内容）；右侧 = 调用该模组的 `DoSettingsWindowContents(rect)` 渲染。本模组设置也要能在这个大页面里展示。
