# Modern Expand Menu

> MD3（Material Design 3）风格的分组右键菜单模组

选中小人后，右键一个存放了多种物品的**单格储物容器**时，弹出一个现代化的 MD3 风格悬浮窗，取代原版扁平的右键菜单：

- 物品按类型分组，每组标题显示**物品图标 + 名称 + 总数**
- 每组下方以子菜单展开操作：**穿戴 / 拾取 / 搬运**（衣物额外有强制穿戴）
- 悬浮窗**跟随鼠标**弹出，**支持滚动**，并设有**最大高度**限制

## 功能特性

- **MD3 动画**：窗口弹出缩放、组标题逐条滑入、子项目串行出现、加载进度条 + 环形进度、加载完成后按手绘曲线平滑回顶（全程可调）
- **完全可自定义**：动画速度、菜单最大高度、每帧处理量、加载时长等均可调；**颜色 16 进制自定义 + 6 套预设调色板**
- **可交互预览**：设置界面可打开独立的扩展菜单预览窗口与杂项样式预览窗口（实时模拟）
- **设置两大类**：「扩展菜单」（常规/动画/颜色/预览）与「其他」（全局样式/颜色/预览），**扩展菜单配色与杂项配色各自独立**
- **全局 MD3 样式（可选开关，默认关）**：原版按钮 / 复选框 / tab / 滚动条 / 输入框 / 滑块统一 MD3 化，使用杂项配色
- **原版 UI 可选 MD3 化（可选开关，默认关）**：窗口边框、命令按钮（征召/解散/攻击）、菜单区块与列表行（药物/食物限制、手术清单、文化列表等）、管制栏（时间表）、信息卡内容（并修复状态栏重叠）、统计界面分组卡片、文化菜单（文化行 + 模因大方块）
- **杂项功能**：跳过上传等待倒计时、空格仅暂停不解除暂停、恢复默认（分组勾选差异对比）、配置导出/导入/管理、三语言（简中/繁中/英文）

## 效果示意

## 安装

将 `ModernExpandMenu` 文件夹放入游戏 `Mods` 目录，在游戏内启用即可。

## 构建

```bat
build.bat
```

构建产物自动复制到 `Assemblies/`，并部署到游戏 `Mods/ModernExpandMenu/`。

## 技术说明

- 框架：`.NET Framework 4.7.2` + `Krafs.Rimworld.Ref 1.6.4871` + `Lib.Harmony 2.3.6`
- Hook 点：`FloatMenuMakerMap.GetOptions`（Postfix）——清空原版选项后弹出自定义悬浮窗
- 操作项复用原版 `FloatMenuOptionProvider_Wear` / `FloatMenuOptionProvider_PickUpItem` 的选项逻辑，保证与原版行为一致（穿戴判定、负重判定等）
- 主题 Token 集中在 `MD3Theme`（扩展菜单）与 `MiscTheme`（杂项）两套配色，所有颜色 / 圆角 / 间距均取自该处，为后续接入 CSS 解析器做外观自定义预留接口

## 当前范围

- 右键命中 **≥2 种物品**（ThingCategory.Item）即接管并分组；右键**殖民者**等非物品目标保持原版菜单
- 多选小人场景暂不接管，保持原版行为
